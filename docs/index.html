How it works

Same pipeline for the Action and the CLI. Diff goes through guards before any model call.

  1. Bound Ignore globs, file caps, character and chunk limits.
  2. Redact Strip common keys and tokens before the prompt is built.
  3. Call or skip OpenAI-compatible chat when a key exists; inventory-only without one.
  4. Upsert one comment Hidden marker <!-- pr-summary-action:v1 --> — update in place, not spam.

What you get

  • Summary, risks, and suggested test plan
  • Conventional Commit title + subject lint
  • EN / FR / Darija headings (Darija RTL-aware)
  • Works with OpenAI, Groq, Ollama, and similar APIs
  • fail-on-error: false so flaky models do not fail CI
  • Keyless dry-run for local and CI self-tests

Quick start

No API key required for the local dry-run.

npm ci
npm test
npm run build
node dist/cli.js dry-run \
  --diff-file tests/fixtures/sample.diff \
  --commits-file tests/fixtures/commits.json \
  --language en --mode full
# In a workflow (posts a comment when dry-run is false)
- uses: mohamedtaqysalmi/pr-summary-action@main
  with:
    api-key: ${{ secrets.OPENAI_API_KEY }}
    mode: full
    fail-on-error: "false"
